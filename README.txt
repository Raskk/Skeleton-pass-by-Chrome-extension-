# How to Install the Extension

1. Download the extension ZIP file.

2. Extract the ZIP file to a folder on your computer.

3. Open Google Chrome.

4. Go to:

   `chrome://extensions`

5. Enable **Developer mode** using the switch in the top-right corner.

6. Click **Load unpacked**.

7. Select the extracted extension folder.

8. The extension is now installed and active.

If you update or replace any files inside the extension folder, return to `chrome://extensions` and click the **Reload** button on the extension.
